# Canvas progressive: implement design/canvas-reorg/03-lienzo-progresivo.html

Objective: today's canvas, simplified for users with basic computer knowledge: labeled tools, a step breadcrumb, three review tabs plus Más, Abrir in the overview with Implement inside a direction, and a first-run guide. Visual spec: `design/canvas-reorg/03-lienzo-progresivo.html`; tokens: `design/system.md`.
Branch: `feat/canvas-progressive` (from local `main` after canvas-ux-quick-wins; design commit 514477518). Work-unit commits only; push/PR are the user's decision.

## Specs

- **S1 Labeled rail.** Artboard: rail items with an icon and a visible label: «Mover», «Comentar», «Ver todo», «Lista», and «Más» at the bottom (EN "Move", "Comment", "Overview", "List", "More"). «Más» opens a menu (same menu pattern as the artboard ⋯ menu, full keyboard behavior) with what the rail had and is rarely used: Sistema de diseño (design system board), Atajos de teclado (?), and «Ver la guía» (S6). Shortcuts V, C, F, [ keep working. The Navigate mode chip reads «Moviéndote por el lienzo · rueda para acercar» (EN "Moving around the canvas · wheel to zoom").
- **S2 Step breadcrumb.** Approved review (verbatim, L2): "Un indicador de pasos arriba, algo como «1 Comparar · 2 Revisar · 3 Elegir · 4 Implementar», con el paso actual marcado, le diría al usuario dónde está y qué sigue. La banda que hicimos para «Implementando» sería el paso 4 de ese indicador." In the top bar after the design selector, compact (artboard). State: a handoff for the open design → steps 1-3 done and 4 current (done once implemented); else focus mode on a direction → 1 done, 2 current; else 1 current. «Comparar» goes to the overview; «Revisar» opens the chosen direction, or the first one; 3 and 4 are not buttons. Current step has `aria-current="step"`, state also in words for assistive technology. The existing top-bar status (#gd-work) stays as step 4's detail, right after the steps, without repeating the state word the step already shows.
- **S3 Connection.** Artboard: a «Conectado» chip in the top bar (EN "Connected"). When a delivery the canvas needs is missing (DELIVERY flags), it reads «Sin conexión» in the warning style and its tooltip/description says what to do (open the canvas from the Pi session with /gentle:design open <slug>), reusing the existing S15 wording.
- **S4 Abrir in the overview, Implement inside.** Approved review (verbatim, L2): "«Implementar esto» … Lo dejaría solo dentro de la propuesta, en modo foco, y en la vista general pondría un único «Abrir»." Each direction header in the overview shows «Abrir» (opens focus); «Implementar esto» / «Cambiar a esta…» appear only in focus mode; the ⋯ menu keeps its items. The handoff row (Elegido/Descartada, stepper, badges) still shows in the overview.
- **S5 Review panel.** Artboard: panel title «Revisión»; tabs «Comentarios (n)», «Calidad (n)» (today's Checks), «Mezcla (n)», and «Más» (a menu with «Historial» and «Petición original», which open those views in the panel). Comments filter «Abiertos · n», «Resueltos · n», «Todos». Empty state «Aún no hay comentarios» + «Abre una propuesta y pulsa «Comentar» sobre lo que quieras cambiar.» Footer: «Enviar al momento» / «Guardar para enviar luego», and «Detalles técnicos» moves from the top bar to the bottom of the panel (same behavior and storage key). Navigator footer note: «Abre una propuesta para comentarla, mezclarla o implementarla.»
- **S6 First-run guide.** Approved review (verbatim, L2): "Una primera vez con tres pasos cortos, que se pueda saltar … «Estas son tus propuestas · Ábrelas para revisarlas · Elige una y pulsa Implementar»." Artboard: a coach card «Primera vez · 1 de 3», title, one sentence, the 3-step list with the current one marked, «Saltar la guía» and «Siguiente» (last step «Entendido»), pointing at the relevant area (directions, an Abrir button, the Implement button or step 4). Shown once per browser (localStorage `gentle-design:guide`), never over an open popover/dialog/focus mode; Esc skips; focus moves into it and returns; «Ver la guía» in «Más» shows it again.
- **S7 Docs, i18n, a11y, tests.** Every string in both catalogs (neutral Spanish, tú forms; EN equivalents); docs/gentle-shell.md and the README Gentle Design row follow the new layout; tokens only from design/system.md; visible focus; reduced motion; tests through the fake DOM; existing tests updated only where these specs change the expected behavior or text.
