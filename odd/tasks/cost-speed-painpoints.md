# Cost and speed pain points: reduce, then prove with a full benchmark

Objective: cut Gentle Shell's per-turn cost and latency without losing quality, then prove it with a before/after benchmark that also measures quality.
Tracking worktree: `.worktrees/cost-speed` (branch `docs/cost-speed-painpoints`, base origin/main `c09189269`). One branch, worktree and PR per task; each PR merges after green CI. Runner: `node --experimental-strip-types --test <files>` in a clean env (`env -i PATH="$PATH" HOME=<short /private/tmp dir> TMPDIR=<same>`); CI is the authority for `pnpm test` and `pnpm run typecheck`.

**S5 — Orchestrator prompt (T4).** Evidence (L2–L4): the full-delegation primary lacks the Language Boundary section (technical artifacts in English), a quality gap; it carries writer-only rules (test-first paragraph, 1,479 B) that only workers apply; in full delegation the orchestrator is about 90% of cost because it carries the always-on prompt for 9–13 turns; the ODD mirror saves the whole document repeatedly (same `topic_key` up to 38 times per session); 6% of `subagent_run` calls are rejected at admission (missing `## Allowed edit surfaces`, verifier without `Risk: item N`, writer without spec).
