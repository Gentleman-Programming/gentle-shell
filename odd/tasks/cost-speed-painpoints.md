# Cost and speed pain points: reduce, then prove with a full benchmark

Objective: cut Gentle Shell's per-turn cost and latency without losing quality, then prove it with a before/after benchmark that also measures quality.
Tracking worktree: `.worktrees/cost-speed` (branch `docs/cost-speed-painpoints`, base origin/main `c09189269`). One branch, worktree and PR per task; each PR merges after green CI. Runner: `node --experimental-strip-types --test <files>` in a clean env (`env -i PATH="$PATH" HOME=<short /private/tmp dir> TMPDIR=<same>`); CI is the authority for `pnpm test` and `pnpm run typecheck`.
