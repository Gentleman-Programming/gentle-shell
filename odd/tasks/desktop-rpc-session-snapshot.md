# Desktop RPC: expose session state sections through get_snapshot over Desktop RPC

Implements #3319 on branch `feat/desktop-rpc-session-snapshot`. Delivery: single PR closing #3319. Test runner: `node --experimental-strip-types --test` (`pnpm test`), plus `pnpm run typecheck`.

## Specs

- S1 (#3319, Proposed outcome, verbatim): Expose the feed's session sections over Desktop RPC, with one owner and one schema:
- S2 (#3319, Proposed outcome, verbatim): `get_snapshot` accepts an optional `sections` param (array of section names). Omitted keeps today's response byte-for-byte (`state.config` only). When present, `state.session` carries the requested sections from the feed projection: `project`, `model`, `context`, `cost`, `usage`, `profiles`, `permission`, `todo`, `changes`, `agents`, `jobs`, `review`, `stats`, `activity`, `pendingQuestion`, `commands`. Unknown section names are `invalid_request`.
- S3 (#3319, Proposed outcome, verbatim): A new `session_snapshot` event carries `{ sections: { …changed sections only } }`, emitted with the feed's own tiers (urgent ≤ 16 ms, otherwise debounced/throttled to ≤ 1/s while busy), and only for sections whose content changed.
- S4 (#3319, Proposed outcome, verbatim): Field discipline, same as the rest of the channel: no `identity` block, no `pid`/`ppid`/`ancestors`, no session file, no agent dir, and no absolute path anywhere. `project.cwd` becomes a display name (basename) and `changes.worktrees[].root` becomes an opaque root label. Arrays keep the feed's existing caps; the response stays within the channel's size bound.
- S5 (#3319, Proposed outcome, verbatim): In-process seam: the feed extension answers a discovery channel (same pattern as `gentle:desktop:jobs-service`), so the RPC extension reads the live projection instead of the file. When the feed is not loaded, requesting sections answers `session_unavailable`; `get_snapshot` without `sections` is unaffected.
- S6 (#3319, Proposed outcome, verbatim): `capabilities` advertises `session_snapshot` only when the seam is wired.
