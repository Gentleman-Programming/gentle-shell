# Installer setup: field reports #2105, #2106, #2109
Objective: fix the three `gentle-shell setup` failures beta testers hit after installing, in Gentle Shell itself, for the next release (the bundled distribution installs the published gentle-pi).
Branch: fix/installer-setup-field-reports (from origin/main bcfab37aa). Delivery: one PR closing #2105, #2106, #2109; one work-unit commit per issue. Test runner: `node --experimental-strip-types --test tests/<file>.test.ts`.

## Specs
- S1. #2105 (verbatim report): "El instalador en macOS falla cuando brew no está instalado en el computador." — `Error: execute install pipeline: run command "brew tap Gentleman-Programming/homebrew-tap": exec: "brew": executable file not found in $PATH`. `gentle-shell setup` must give Gentle AI the pinned Engram it already acquired, in a way Gentle AI 4.0.0 honors (it ignores `GENTLE_AI_ENGRAM_BIN`, and looks up `engram` on PATH first), so no `brew` is needed. The user's own PATH and Engram are not changed.
- S2. #2106 (verbatim report): "Luego de instalar gentle-shell en linux debian, al ejecutar gentle-shell vuelve a instalar unos paquetes, aparece este error en pantalla y no aparece la barra lateral." — after a successful `gentle-shell setup` (what both installers run), the first `gentle-shell` launch must not run the automatic setup again. The `[Skill conflicts] ... ~/.agents/skills/_shared/SKILL.md` file is a legacy Gentle AI artifact that gentle-shell never writes (assumption to confirm in the task; no deletion of user files without evidence).
- S3. #2109 (verbatim report): "El instalador en windows 11 26H2 falla al instalar \"pi install npm:gentle-pi\"." — `Error: execute install pipeline: run command "pi install npm:gentle-pi": exit status 1`. Fix the Windows postinstall identity check from #1258 (lstat `dev = 0` vs fstat volume id) so the same file is recognized, without weakening the check on POSIX.
- S4. User decision (verbatim): "Los tres" — "#2105 (Engram fijado en el PATH del setup), #2106 (marker tras setup) y #2109 (confirmar y corregir #1258), cada uno con su test y PR."
