### Read a trace

1. Compare `process_tag`; a different value means the process-local journal cannot be joined.
2. Compare `scope_tag`; different values in one process mean different retained-route maps, not proof of *why* the session changed. Match an `offered[].route_tag` to capture `attempted[]` within that process. These are ephemeral keyed HMAC tags, not authority tokens.
3. Read `events` by `sequence`: `registered`, `removed` (with `no_collect_transition`, `changed_collect_set`, `terminal` or `capacity_eviction`), `suppressed`, `collision`, `rejected`. A grouped rejection's event tags the *ordered group*, not a purported failing member; `attempted[]` lists its members. `previous_event` is merely the latest retained event for an attempted tag, not a causal verdict.
4. `offered[].retained` reports **map membership only**, never current-target eligibility. A non-current STATUS can report both retained and suppressed without deleting the old route. `truncated`/`history_truncated` means the 128-event process-local ring may have lost earlier context. Neither absence of a prior event nor a scope mismatch alone proves the reported root cause. Do not paste the full STATUS publicly: the pre-existing `collectBindings` field still contains provider bytes even though `route_diagnostic` does not.
