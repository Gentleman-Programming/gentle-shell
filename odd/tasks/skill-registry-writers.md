**S6 — Deterministic bytes and publication (engineering contract).** Render UTF-8 with LF and exactly one final LF; no time, PID, runtime rows, writer identity, or runtime count. The following is the exact shared template; `{sources}` is one `- <path>` per existing root in S5 order, using cwd-relative native paths for roots inside cwd (`.` for cwd) and absolute paths otherwise; `{rows}` is one row per S5 winner. Substitute the cwd basename for `{project}`. Empty source/row lists add no placeholder lines. In each row trim cells, replace newline with space and `|` with `\|` (one backslash), use `—` for an empty cell, and use native absolute logical paths.

```text
# Skill Registry — {project}

<!-- Shared disk skill registry; generated by Gentle Shell or Gentle AI. -->

## Sources scanned

{sources}

## Contract

**Delegator use only.** This disk index is not a summary and excludes session-only runtime skills. Pi delegators use their effective session view; other delegators use these rows. Pass exact `SKILL.md` paths to subagents.

`SKILL.md` remains the source of truth. Do not inject generated summaries or compact rules by default; pass paths so subagents load the full runtime contract and preserve author intent.

## Skills

| Skill | Trigger / description | Scope | Path |
| --- | --- | --- | --- |
{rows}

## Loading protocol

1. Match task context and target files against the effective view's `Trigger / description` column.
2. Pass only the matching `Path` values to the subagent under `## Skills to load before work`.
3. Instruct the subagent to read those exact `SKILL.md` files before reading, writing, reviewing, testing, or creating artifacts.
4. If no matching skill exists, proceed without project skill injection and report `skill_resolution: none`.
```

A row is ``| `<name>` | <description> | <scope> | `<path>` |``. Empty-list substitution removes only the placeholder line, not the surrounding blank lines. Recompute the disk scan and rendered bytes on every refresh, including non-forced refreshes: do not trust old fingerprints, metadata or cache existence to skip validation. Compare actual registry bytes with the render; equal bytes are a no-op for the registry, including a deliberate force after recomputation. This catches same-size/restored-mtime description changes without requiring a shared metadata fingerprint; changes only to unrendered skill body need not rewrite the index.

Keep `.atl/.skill-registry.cache.json` for existing consumers as a **non-authoritative** deterministic hint: exactly `{"schema":1,"registry_sha256":"<lowercase SHA-256 of registry UTF-8 bytes>"}\n`. Compare actual cache bytes and atomically repair when different. Never accept a cache hit without comparing the actual registry with the newly rendered bytes; a cache cannot certify a different registry or a stale disk scan. Missing, corrupt, old Go schema-5/Pi schema-9 fingerprints and a registry/cache mismatch self-heal on an allowed refresh. Reuse CLI `filemerge.WriteFileAtomic`; Pi stages unique files in the target directory and atomically renames complete files, preserving existing target modes and the established unavailable/error behavior. No speculative process-wide maps or locks. Publish registry before its cache; each file is atomic, **not an atomic pair**. A crash/interleaving may leave a mismatched pair, but no later refresh may falsely accept it, and after writers and disk changes stop a subsequent refresh converges. Do not claim a stale scan cannot transiently win a race.

Preserve Pi automatic Git-tracked registry/cache/child-ignore protection, fail-closed Git detection, child/flag opt-outs and deliberate `/skill-registry:refresh` override. Keep Go's existing project-root guard, `--quiet`, `--no-gitignore`, `--force`, `--cwd`, `list` behavior and intentional refresh interface; its current hook invokes the same CLI refresh and does not have Pi's tracked-target check. Preserve command results/messages where possible and document the force/equality behavior accurately. Do not silently clobber protected Pi targets during migration.
